# Agent skills

An agent is a coding assistant. A skill is a folder of instructions.
Plain skills live in `agents/skills/` and remain usable without a manager.
The [Fleet agent generator](https://github.com/jeremyspofford/fleet/blob/main/docs/AGENTS.md) owns agent discovery, native settings, links, and output records.
It installs no agents and performs no login. Keep credentials outside this content repository.
